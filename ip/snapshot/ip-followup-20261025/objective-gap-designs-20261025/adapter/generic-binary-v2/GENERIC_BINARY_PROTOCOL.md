# Generic binary-IP full Neural Diving pilot, version 2

This independent adapter supports any finite original binary formulation and
an explicit signed affine map c=offset+coefficients@feature. It never edits
the sealed station, UC, or knapsack studies. The original problem matrix,
bounds, signed coefficients and binary domains are retained. For the selected
coupled-bundle family, A/B profits are 0.25 each and C profit is xi with
xi Uniform[0.1,2.5]; reported profit includes the entire original gross
objective. The base bundle profit is never subtracted or otherwise recentered.

Before fitting, a separate training-only cohort manifest fixes every selected
case identifier and absolute directory, source training/metadata/affine hashes,
D, row count, feature dimension, n and exact global K. All selected cases are
retained. The adapter rejects a source or dimension change, or a training prefix
whose exact rational affine rank differs from the selected global K. Data
generation and reference/geometry screens are independent of ND training.
The cohort manifest contains no development or confirmation arrays, and the
training loader never opens either bank.

The selected coupled-bundle schema additionally checks the original interleaved
A/B/C coordinates, A/B gross profits 0.25, C gross profit equal to the feature
xi in [0.1,2.5], the exact signed affine map, every original local bundle row
and every global C-conflict row. Either a declared three-item capacity model
or the declared pairwise convex-hull packing model can be checked; the frozen
cohort source hashes and local-formulation declaration fix which is primary.
The assertor adds no rows or optimizer identities and is not a learned feature.

ND receives only the same n original globally certified training optima used
by Ours. All original rows and coefficients are supplied to the original graph
and certified root-LP feature extractor. Analytic optimizer identities and
enumerated independent-set catalogs certify data and K only; they are never
ND graph features, extra labels, or manually supplied compression equations.
Ours computes its affine space from the training optimizers over the rationals.

The original full complete-predictor fitting remains unchanged: six-layer GCN,
widths 32 and 64, 13 formulation plus 15 certified root-LP features, Adam 0.001,
batch size 16, gradient clipping 5, both widths' full 1200-step training sanity
schedule, up to 150 warmup epochs with patience 20, training-only matched-K
architecture/epoch selection, then all-n refitting. The already disclosed
singleton-certified-optimum label pools and omission of five unused mask
networks are retained. No additional diving policy or shortened training
schedule is introduced. All reused trainer/runtime files are byte copies of
the previously sealed implementation.

Common coordinate scope contains every original binary variable. ND fixes
exactly D-K original coordinates using its existing MAP/confidence rule, then
solves the original restricted IP. Its training validation uses the same rule
and K. Ours adds its learned affine space to the same original IP. The signed
minimization reference is strictly negative because original optimal profit
is positive. Primary profit ratio is achieved original profit divided by
original optimal profit, equivalently returned minimization objective divided
by reference objective. Arbitrary objective-value constants are forbidden.
The affine feature-map offset is a vector of actual fixed coefficients, not
an objective-value constant.

The generic ratio implementation retains zero and negative returned profits;
there is no clipping or unrestricted fallback. For the current all-positive
gross-profit formulation, feasible original returns naturally have nonnegative
profit. All returned points are checked in the original domain and their
restriction. Invalid, missing or over-30-second results remain explicit with
null primary ratio, and ratio denominators are reported. Recovery denominator
contains all development cases. Time is measured immediately after original
inference/restricted solve and before independent result validation.

Development bank access requires a complete guard-valid ND checkpoint even
when only Ours is requested. Resume verifies canonical payload checksums,
case/method/index/source identity, actual K, original and restricted feasibility,
timeliness, objective, profit ratio and recovery. Completion summaries include
all record file hashes. This is an exploratory development pilot; no independent
confirmation stream is generated or read by the adapter.

Publication uses a same-directory UUID temporary, fsync, and no-overwrite
Windows os.rename. The shared trainer's JSON publisher is bound to the same
publication function at runtime, while its serialized data and scientific
source remain unchanged. Two independent single-thread CPU workers may run;
concurrent wall times are not exclusive training-time benchmarks.
